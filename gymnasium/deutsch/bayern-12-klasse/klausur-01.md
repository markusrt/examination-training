## Aufgabe 1 – Lyrik: Gedichtanalyse (30 BE)

Analysiere das folgende Gedicht von Joseph von Eichendorff.

---

**Joseph von Eichendorff: Mondnacht (1837)**

| | |
|---:|:---|
| 1 | Es war, als hätt der Himmel |
| 2 | Die Erde still geküsst, |
| 3 | Dass sie im Blütenschimmer |
| 4 | Von ihm nun träumen müsst. |
| 5 | |
| 6 | Die Luft ging durch die Felder, |
| 7 | Die Ähren wogten sacht, |
| 8 | Es rauschten leis die Wälder, |
| 9 | So sternklar war die Nacht. |
| 10 | |
| 11 | Und meine Seele spannte |
| 12 | Weit ihre Flügel aus, |
| 13 | Flog durch die stillen Lande, |
| 14 | Als flöge sie nach Haus. |

---

**a)** Gib den Inhalt des Gedichts strophenweise in eigenen Worten wieder und beschreibe den formalen Aufbau (Strophen, Versmaß, Reimschema, Kadenz). [8 BE]

**b)** Analysiere die sprachlichen Mittel des Gedichts. Gehe dabei besonders auf Bildlichkeit (Metaphern, Personifikationen, Vergleiche) und Klangwirkung ein. [10 BE]

**c)** Ordne das Gedicht in die Epoche der Romantik ein. Erläutere, welche typischen Motive und Merkmale der Romantik in diesem Gedicht erkennbar sind. [7 BE]

**d)** Deute die letzte Strophe: Was könnte mit dem Fliegen „nach Haus" (Z. 14) gemeint sein? Beziehe mindestens zwei verschiedene Deutungsmöglichkeiten ein. [5 BE]

## Aufgabe 2 – Epik: Analyse eines Erzähltextauszugs (35 BE)

Analysiere den folgenden Textauszug aus Franz Kafkas Erzählung „Die Verwandlung" (1915).

---

**Franz Kafka: Die Verwandlung (1915) – Beginn der Erzählung**

| | |
|---:|:---|
| 1 | Als Gregor Samsa eines Morgens aus unruhigen Träumen erwachte, fand |
| 2 | er sich in seinem Bett zu einem ungeheueren Ungeziefer verwandelt. |
| 3 | Er lag auf seinem panzerartig harten Rücken und sah, wenn er den |
| 4 | Kopf ein wenig hob, seinen gewölbten, braunen, von bogenförmigen |
| 5 | Versteifungen geteilten Bauch, auf dessen Höhe sich die Bettdecke, |
| 6 | zum gänzlichen Niedergleiten bereit, kaum noch erhalten konnte. |
| 7 | Seine vielen, im Vergleich zu seinem sonstigen Umfang kläglich |
| 8 | dünnen Beine flimmerten ihm hilflos vor den Augen. |
| 9 | |
| 10 | „Was ist mit mir geschehen?" dachte er. Es war kein Traum. Sein |
| 11 | Zimmer, ein richtiges, nur etwas zu kleines Menschenzimmer, lag |
| 12 | ruhig zwischen den vier wohlbekannten Wänden. Über dem Tisch, auf |
| 13 | dem eine auseinander gepackte Musterkollektion von Tuchwaren |
| 14 | ausgebreitet war – Samsa war Reisender –, hing das Bild, das er |
| 15 | vor kurzem aus einer illustrierten Zeitschrift ausgeschnitten und |
| 16 | in einem hübschen, vergoldeten Rahmen untergebracht hatte. Es |
| 17 | stellte eine Dame dar, die, mit einem Pelzhut und einer Pelzboa |
| 18 | versehen, aufrecht dasaß und einen schweren Pelzmuff, in dem ihr |
| 19 | ganzer Unterarm verschwunden war, dem Beschauer entgegenhob. |
| 20 | |
| 21 | Gregors Blick richtete sich dann zum Fenster, und das trübe |
| 22 | Wetter – man hörte Regentropfen auf das Fensterblech aufschlagen – |
| 23 | machte ihn ganz melancholisch. „Wie wäre es, wenn ich noch ein |
| 24 | wenig weiterschliefe und alle Narrheiten vergäße", dachte er, aber |
| 25 | das war gänzlich undurchführbar, denn er war gewohnt, auf der |
| 26 | rechten Seite zu schlafen, konnte sich aber in seinem gegenwärtigen |
| 27 | Zustand nicht in diese Lage bringen. Mit welcher Kraft er sich auch |
| 28 | auf die rechte Seite warf, immer wieder schaukelte er in die |
| 29 | Rückenlage zurück. |

---

**a)** Fasse den Inhalt des Textauszugs zusammen und bestimme die erzählerische Situation (Erzählperspektive, Erzählverhalten, Zeitgestaltung). [8 BE]

**b)** Untersuche Sprache und Stil Kafkas in diesem Auszug. Gehe dabei auf Satzbau, Wortwahl und die besondere Wirkung des nüchternen Erzähltons angesichts des fantastischen Geschehens ein. [10 BE]

**c)** Analysiere, wie Kafka das Verhältnis zwischen der fantastischen Verwandlung und der alltäglichen Umgebung gestaltet. Welche Wirkung erzeugt dieser Kontrast beim Leser? [10 BE]

**d)** Erläutere, inwiefern sich in diesem Textauszug bereits zentrale Themen der Erzählung ankündigen (z. B. Entfremdung, Identität, Isolation). [7 BE]

## Aufgabe 3 – Drama: Szenenanalyse (35 BE)

Analysiere den folgenden Szenenausschnitt aus Georg Büchners Dramenfragment „Woyzeck" (entstanden 1836/37, postum veröffentlicht 1879).

---

| 1 | HAUPTMANN. Langsam, Woyzeck, langsam; eins nach dem andern! |

| 27 | |

| 33 | |

| 46 | HAUPTMANN. Was sagt Er da? Was ist das für eine kuriose Antwort? |
